# Tasca S1.03 - Arrays

Descripció: Exercicis per practicar la creació, modificació i recorregut d'arrays en PHP.

## Tecnologies

* PHP
* XAMPP
* Visual Studio Code

## Instal·lació

1. Clonar el repositori:

```
git clone https://github.com/jordiartigues/Tasca-S1.03.git
```

2. Obrir el projecte amb Visual Studio Code.

3. Per executar els exercicis des de la terminal, entrar a la carpeta del projecte:

```
cd Tasca-S1.03
```

4. Entrar a la carpeta dels exercicis:

```
cd nivell-1
```

5. Executar l'exercici:

```
php exercici1.php
```

## Estructura del projecte

```
Tasca-S1.03/
└── nivell-1/
    ├── exercici1.php
    ├── exercici2.php
    └── exercici3.php
```

## Demo

Els exercicis s'executen localment amb PHP. No hi ha demo online perquè es tracta d'exercicis de PHP.
